# API.md — конспект TVmaze API для ShowFinder

##  Основна таблиця

| Питання | Що каже документація | Що показав запит (адреса) |
| --- | --- | --- |
| **Ендпоїнт пошуку за назвою, параметри** | Розділ *Show search*: URL `/search/shows?q=:query`. Пошук нечутливий до невеликих помилок у запиті (fuzziness 2), результати — у порядку релевантності. **Єдиний параметр — `q`.** | `GET https://api.tvmaze.com/search/shows?q=girls` → `200`, масив із 10 результатів. `GET https://api.tvmaze.com/search/shows?q=Law%20%26%20Order` → `200`, перший результат — «Law & Order» (id 562): символ `&` працює лише в закодованому вигляді. **Перевірено: параметр `page` не підтримується** — `?q=girls&page=1` повернув ті самі 10 id, що й без нього. Не додавати. |
| **Форма відповіді пошуку** | «Results are returned in order of relevancy (best matches on top) and contain each show's full information». API дотримується HAL: у ресурсів є `_links`, а вбудовані дані — в `_embedded`. | `GET https://api.tvmaze.com/search/shows?q=girls` → `200`, JSON-масив із 10 елементів виду `{"score": 0.889806, "show": {...}}`. У `show` — **повний** об'єкт серіалу (26 полів). Для `renderResults` треба віддавати `show`, а не весь елемент пошуку. |
| **Ендпоїнт серіалу; як отримати епізоди й акторів одним запитом** | *Show main information*: URL `/shows/:id`, «This endpoint allows embedding of additional information». Розділ *Embedding*: `?embed=episodes`; кілька зв'язків — масивним синтаксисом `?embed[]=episodes&embed[]=cast`. | **Один запит:** `GET https://api.tvmaze.com/shows/139?embed[]=episodes&embed[]=cast` → `200`, у відповіді з'явився ключ `_embedded` з `episodes` (62) і `cast` (8). Без embed — 3 запити: `/shows/139` + `/shows/139/episodes` (62) + `/shows/139/cast` (8). |
| **Поля серіалу, що можуть бути `null`** | Розділ *Images*: «If no image exists yet, the *image* property will be NULL». Решта полів — nullable за схемою; `network` і `webChannel` заповнюються зазвичай по одному. | `GET https://api.tvmaze.com/shows/139` («Girls»): `ended: null`, `webChannel: null`, `dvdCountry: null`.<br>`GET https://api.tvmaze.com/shows/254` («World Series of Poker»): `runtime: null`, `ended: null`, `officialSite: null`, **`network: null`** (є лише `webChannel: "PokerGO"`), `dvdCountry: null`.<br>`GET https://api.tvmaze.com/shows/410` («Rival Survival»): `premiered: null`, `averageRuntime: null`, **`rating.average: null`**, `officialSite: null`, `webChannel: null`.<br>`GET https://api.tvmaze.com/shows/1124` («Becoming Human»): **`image: null`** (інакше `image` — об'єкт `{medium, original}`).<br>`genres` може бути порожнім масивом `[]` — напр. `GET https://api.tvmaze.com/shows/272` («Talking Dead»). |
| **Що повертає пошук без результатів** | Окремо не описано; сказано лише, що результат — масив. | `GET https://api.tvmaze.com/search/shows?q=zzqx` → **`200`** і тіло `[]`. Тобто це **не помилка і не 404**, а порожній масив. Для порівняння: `GET https://api.tvmaze.com/singlesearch/shows?q=zzqx` → `404`. |
| **Що повертає неіснуючий id** | *Show Lookup*: «If the given ID can be matched, a HTTP 301 redirect … will be returned. Otherwise, a HTTP 404 is sent». Для `/shows/:id` — те саме: `404`. | `GET https://api.tvmaze.com/shows/999999999` → **`404`**, тіло — JSON `{"name":"Not Found","message":"","code":0,"status":404}`. Проміс `fetch` при цьому **не відхиляється** — треба перевіряти `response.ok`. Також `GET https://api.tvmaze.com/shows?page=999` → `404` з тілом `[]`. |
| **Ліміт запитів і що робити на 429** | *Rate Limiting*: «API calls are rate limited to allow **at least 20 calls every 10 seconds** per IP address. If you exceed this rate, you might receive an HTTP 429 error… simply let your client **back off for a few seconds** when it receives a 429»; «it's useful to gracefully handle HTTP 429 responses: simply **retry the request after a small pause** instead of treating it as a permanent failure». Радять also встановлювати власний `User-Agent`. | Ліміт — 20 запитів / 10 с з однієї IP-адреси. Спеціальних заголовків ліміту (`X-RateLimit-*`, `Retry-After`) сервер **не надсилає** — у відповіді їх немає, тому паузу задає клієнт: **почекати 2–5 с і повторити запит один раз**; далі — помилка й кнопка «Спробувати ще». Інакші помилки автоматично не повторюємо. |
| **Кешування: що кешує TVmaze і що — браузер** | *Caching*: «All output is cached by our **HTTP load balancers** for **60 minutes**, so when information is updated on the site, please allow up to 1 hour for the changes to propagate to the API». Винятки: *Show index* (`/shows?page=N`) і *Full schedule* — до 24 годин. | `GET https://api.tvmaze.com/search/shows?q=girls` → Response Headers: **`cache-control: public, max-age=3600`**. Тобто 60 хвилин кешує **браузер** (і будь-який проксі) — сам TVmaze/SQLite відповідь не кешує, у нього кеш балансувальника. Наслідок: браузерний кеш не замінює кеш застосунку — повторне відкриття серіалу все одно не піде в мережу, тільки якщо застосунок сам збереже дані. `Retry-After` сервер не надсилає; `date` і `server` скрипту не видно (див. розділ 4). |
| **CORS: що обіцяє документація і що показав експеримент 12** | *CORS*: «**All endpoints are CORS enabled**, which means our API can be used directly in web applications without having to resort to JSONP or HTTP proxying». | `GET https://api.tvmaze.com/search/shows?q=girls` → Response Headers: **`access-control-allow-origin: *`** → звичайний GET без власних заголовків проходить. Експеримент 12: запит із `headers: { 'Content-Type': 'application/json' }` → браузер спершу надсилає **preflight `OPTIONS`** → TVmaze відповідає **`405`** без CORS-заголовків → запит падає з CORS-помилкою (у Network видно `OPTIONS 405`, а сам `GET` не надсилається). `headers: { Accept: 'application/json' }` → без preflight, `200`. Висновок: «CORS enabled» означає, що дозволено **прості** запити, а не будь-які заголовки. |

You can satisfy the attribution requirement by **linking back to TVmaze** from within your application or website, for example using the URLs available in the API». | Ліцензія — не HTTP-відповідь, а умова використання: `CC BY-SA 4.0`, <https://creativecommons.org/licenses/by-sa/4.0/>. Атрибуція = посилання на `https://www.tvmaze.com` (у футері застосунку) і на сторінку серіалу `show.url`, яка є в кожному об'єкті серіалу, напр. `https://www.tvmaze.com/shows/139/girls` (перевірено в `GET https://api.tvmaze.com/shows/139`). |
